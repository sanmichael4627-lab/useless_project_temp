### Project Description
PRAYER.exe is a web application that acts as an ethereal Heavenly Gate, converting your daily chaos and existential dread into soothing prayers and practical earthly solutions.

### The Problem (that doesn't exist)
Modern humans spend hours spiraling about minor awkward moments—like saying "you too" to a waiter who said "enjoy your meal"—without a direct digital celestial hotline to instantly absolve their overthinking.

### The Solution (that nobody asked for)
A full-stack web app featuring a Genshin Impact-style slow-motion 3D celestial door entrance that opens into an interactive AI portal. It translates mental chaos into a 3-step reframed prayer and actionable advice using the Gemini AI API and a zero-dependency offline rule engine.
